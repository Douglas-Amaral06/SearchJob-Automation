# Projeto SearchEmprego

Objetivo:
Criar um agregador de vagas que economiza tempo do candidato.

Stack:
- Backend: FastAPI
- Frontend: React + Vite + Tailwind
- Python
- Playwright
- SQLite

Arquitetura:
- app/services/
- main.py
- frontend/src/

Fontes atuais:
- Adzuna
- Jooble

Fontes futuras:
- Gupy
- InfoJobs
- LinkedIn
- Indeed

Funcionalidades existentes:
- Busca por cargo
- Busca por cidade
- Modalidade
- Paginação
- Remoção de duplicados
- Botão "Já me candidatei"
- Filtro PCD
- Filtro por data

Objetivo futuro:
Criar uma automação que realize candidaturas automaticamente utilizando Playwright.

Nunca altere o padrão de retorno da API sem necessidade.

Sempre preserve compatibilidade com o frontend.
